OSFile Windows Guide

This is the guide page. Follow the steps below to install OSFile on Windows.

Quick steps

  1. Go to the Windows installer page: Install for Windows.
  2. Download the installer bundle and extract it.
  3. Run OSFile.installer.exe and follow the prompts.

Notes

If the installer file is missing you will be redirected to the Install page with troubleshooting links.
